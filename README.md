# 🎓 SkillSwap

> **Share Skills. Learn Together. Grow Together.**

SkillSwap is a student-to-student skill exchange platform designed for college communities. It helps students discover useful skills, find people who can teach them, and exchange their own skills in return.

The platform uses a smart matching system to identify students with compatible learning and teaching goals.

---

## 🚀 Features

- 🎯 **Smart Skill Matching**  
  Find students who can teach the skill you want to learn.

- 🔄 **Two-Way Skill Exchange**  
  Discover mutual matches where two students can teach each other.

- 🔍 **Explore Skills**  
  Search and filter students based on their skills and categories.

- 👤 **Student Profiles**  
  View skills, learning goals, availability and other profile information.

- 📊 **Personal Dashboard**  
  Track skills, learning goals, swap requests and completed exchanges.

- 📈 **Trending Skills**  
  Discover the most popular skills among students.

- 🏆 **Skill Contributors Leaderboard**  
  Recognize students who actively share their knowledge.

- 🗺️ **Skill Map**  
  Explore the relationship between different skills and student interests.

- 💾 **LocalStorage Support**  
  Store student data and swap requests directly in the browser.

- 🔔 **Interactive Notifications**  
  Get feedback for actions such as adding skills and sending swap requests.

- 📱 **Responsive Design**  
  Works across desktop, tablet and mobile screens.

---
